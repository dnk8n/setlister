# out/

Each run writes a folder here named after the set, containing:

- `description.txt` – paste-ready tracklist (timestamps become YouTube chapters)
- `tracklist.md` – links, confidence and a short note per track
- `setlist.json` – everything, machine readable
- `README.md` – how to publish it

Text results may be committed (they're small and useful as examples); media never is.
