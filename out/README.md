# out/

Each run writes a folder here named after the set, containing:

- `description.youtube.txt` – paste into the YouTube description (timestamps become chapters)
- `description.soundcloud.txt` – paste into the SoundCloud description
- `tracklist.mixcloud.txt` – paste into Mixcloud's tracklist box
- `tracklist.md` – links, confidence and a short note per track
- `setlist.json` – everything, machine readable
- `README.md` – how to publish it

Everything in here except this README is gitignored: results are specific to your set.
Paste them where they belong (see each folder's README). For a worked example, see
[docs/case-studies/](../docs/case-studies/).
